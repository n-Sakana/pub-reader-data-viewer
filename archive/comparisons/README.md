# 比較実験アーカイブ

製品方式を選ぶために行った凍結済み比較です。

- `one-to-one/` — 100 万行・番号1が一意の C# / VBA 比較
- `one-to-many/` — 10 万行・自前ハッシュ / 標準連想配列 × C# / VBA 比較
- `build/` — 当時の生成・計測スクリプト

結果は各フォルダの `results.md` にあります。現行製品のビルド対象ではありません。元の配置で再実行する場合は commit `017bb3e` を使います。

共通の `header.cmd` と `header.vbs` は現行製品でも使うため `src/launcher/` に置いてあります。

# サンプルで操作を試す

このアプリは、data内の01〜03のCSVをまとめて「統合台帳.xlsx」を作ります。手動検索・自動検索とも、この統合台帳から該当する番号のデータを探し、決済状況などを表示します。04のCSVは削除対象の照合に使います。
このサンプルでは、台帳作成・手動／自動検索・確認状態の変更と送信・帳票出力・削除・5月分への更新を順に試します。

## フォルダの見方

このREADMEがある場所を「アプリのフォルダ」と呼びます。

- ReaderDataViewer.vbs：起動ファイル。
- data：読み込むCSV4枚と、作成後の統合台帳・ログ。CSVは固定名で上書きし、増やしません。
- 追加CSVデータ → 5月分（3件追加）：更新を試すためのCSV4枚。
- output：帳票出力時に作られるフォルダ。
- settings.json：取込設定。今回の更新では変更しません。
- lib・src・tools・web：アプリの動作に必要なファイル。

## 操作の意味

- 指定したアプリの入力欄を監視し、入力された番号を自動検索できます。監視対象は「設定」から変更でき、このサンプルではメモ帳を設定済みです。

- 画面上部右側のボタンが「未確認／確認済」です。手動検索は表示だけ。メモ帳からの自動検索は、決済状況が「済」の案件だけ確認済にします。未決済を自動で確認済にしないためです。自動・手動のどちらで確認済にした場合も、このボタンで未確認へ戻せます。
- 「確認状態を一括送信」で確認状態をdata内の統合台帳に反映します。送信前は手元の変更です。
- 台帳の作成・更新、確認状態の送信、削除の履歴は、data内の「統合台帳-操作ログ-端末名.csv」に自動で残ります。いつ・誰が・どの端末で何をしたか、台帳の件数と内容を確認できます。「操作ログ.log」はアプリの動作やエラーを調べるための記録です。
- 起動時にもCSVの差分を調べます。差分の確認で「はい」を選ぶと更新するので、続けて「データ更新」を押す必要はありません。起動中にCSVを差し替えた場合は「データ更新」を使います。
- 削除した記録は統合台帳から外し、data内のarchivedフォルダへ別のExcelで保存します。後のCSVに同じデータが含まれていても、台帳へ戻さないために保存しています。archivedのファイルは消さず、統合台帳と一緒に保管してください。

## 確認の手順

起動前に、アプリのフォルダのdataを開き、01〜04のCSVが4枚あり、統合台帳.xlsxはまだないことを確認します。最初のCSVは4月分です。

1. ReaderDataViewer.vbsを開き、台帳作成の確認で「はい」を選ぶ。dataの01〜03から同じdata内に統合台帳.xlsxができ、画面左下の「台帳件数」が3件になる。
2. 画面上部の「識別番号／受付番号」欄で AB10000001CD を検索する。AB10000001CDの決済状況が「済」、確認状態は「未確認」のまま。右の「クリア」で表示を消す。
3. メモ帳を開き、本文に AB10000001CD だけを入力する。Enterや検索ボタンは押さない。AB10000001CDが自動検索され、画面上部右側が「確認済」になる。自動検索されない場合は、メモ帳の窓とタブが一つずつになっていることを確認する。
4. メモ帳の本文をすべて消し、AB10000002CD に置き換える。AB10000002CDは未決済なので、自動検索しても「未確認」のまま。
5. 表示中のAB10000002CDで、画面上部右側の「未確認」ボタンを押し、手動で「確認済」にする。
6. 同じボタンの「確認済」をもう一度押し、戻す確認で「はい」を選ぶ。「未確認」に戻ったことを確認する。
7. メモ帳の本文を空にし、アプリ右下の「確認状態を一括送信」で確定する。確認状態がdata内の統合台帳に反映され、検索欄の番号が消える。
8. アプリを閉じて開き直し、AB10000001CD を手動検索する。「確認済」が残り、送信ボタンの左の未送信件数が0件になっている。AB10000002CDは「未確認」のまま。
9. 画面下部の「帳票出力」を開き、出力先はそのままで「OK」。アプリのフォルダにoutputが作られ、選んだ項目のCSVができる。名前は export-年月日-時分秒.csv（例：export-20260911-093000.csv）。
10. 画面下部の「データ削除」を実行する。dataの04に一致し、台帳で確認済のAB10000001CDが削除される。左下の台帳件数が2件になり、data内のarchivedに削除記録のExcelができる。
11. アプリを閉じる。「追加CSVデータ」→「5月分（3件追加）」のCSV4枚を、アプリのdataへ上書きコピーする。名前は4月分と同じ。CSVだけを入れ替え、統合台帳.xlsxはそのまま残す。
12. アプリを開き、「CSVから読み取った内容と、保存済みの統合台帳に違いがあります」の確認で「はい」を選ぶ。data内の統合台帳が更新され、左下の台帳件数が5件になる。
13. 画面上部で AB10000009CD を検索する。5月分で新しく追加した案件が表示される（ほかの新規番号は AB10000010CD、AB10000011CD）。
14. AB10000002CD を検索する。既存のAB10000002CDが、未決済から「済」に更新されていれば完了。

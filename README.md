# Reader Data Viewer — レイアウト固定版

CSV・Excelの入力を台帳にまとめ、番号で検索して処理状態を共有するWindowsアプリです。画面の配置を固定した版です。表示する値・取り込み方・判定条件はJSONで設定します。

## はじめに

1. ZIPを空のフォルダへすべて展開します。
2. `ReaderDataViewer.vbs` を開きます。
3. 台帳の作成案内が出たら、表示された保存先を確認して作成します。

64ビットWindows、Windows PowerShell 5.1、Microsoft Edge WebView2 Runtimeが必要です。Excelの起動は不要です。

サンプル付きZIPには架空の入力4ファイルが入っています。入力が付いていない場合は、管理担当から受け取った同じ版の `settings.json` と入力ファイルを配置してから起動します。

## ふだんの操作

1. **更新**：`data` 内の入力ファイルを差し替え、「データ更新」を実行します。ファイルを置くだけでは更新されません。
2. **検索**：番号を入力して検索します。候補が複数ある場合は対象の案件を選びます。
3. **処理状態を付ける**：内容を確認して「処理済」にします。同梱設定では、自動読取で確定した決済済みの案件だけ自動で付きます。
4. **保存**：「変更をまとめて送信」を実行します。未送信件数が0になったことを確認します。
5. **削除・復元**：「データ削除」は削除用入力と一致し、処理済みを送信した案件が対象です。削除した案件は「削除済み」から選んで復元できます。

送信済みの処理済み案件は、再取込でも内容と状態を保ちます。削除済みの案件は、再取込だけでは復活しません。この説明は同梱設定での動作です。

最初の1件は `AA10000000AA` で試せます。手入力検索 → 処理済み → 送信 → データ削除の順で、サンプルの台帳は100件から99件になります。繰り返し試すときは、別の空フォルダへ展開します。

## フォルダの見方

| 場所 | 用途 |
|---|---|
| `ReaderDataViewer.vbs` | 起動 |
| `settings.json` | このアプリ用の設定 |
| `data/` | 入力ファイルと、設定された台帳 |
| `output/` | 帳票の出力先 |
| `manual/` | 設定・保護・移行の詳しい説明 |
| `samples/` | サンプル付きZIPの練習用入力と確認手順 |
| `tools/` | 診断用起動・旧台帳の移行 |
| `src/`・`web/`・`lib/` | 起動に必要なプログラム一式。フォルダごと保管します |

台帳や出力の保存先は設定によって変わります。アプリの種類と版の識別情報は `manual/release.json` にあります。

## 業務で使うとき

管理担当が確認した設定とデータを使います。既存の設定・台帳を同梱サンプルで上書きしないでください。レイアウトJSON設定版と固定版では、使うJSONの画面定義が異なります。

台帳作成後は、入力形式・結合方法・保存列などの業務定義を変更できません。旧台帳に移行の案内が出た場合は、[台帳の保護と移行](manual/PROTECTION-GUIDE.md)を管理担当が確認します。処理済み案件の内容を訂正するときは、未処理へ戻して送信してから更新します。

## 困ったとき・詳しい使い方

起動できない場合は `tools/ReaderDataViewer.cmd` を開き、表示された内容を管理担当へ伝えます。起動ログは `%LOCALAPPDATA%/ReaderDataViewer/logs/feedback.log` にあります。

自動読取の前面表示はWindowsの制限で切り替わらない場合があります。その場合も照会は続きます。

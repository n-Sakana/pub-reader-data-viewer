READER DATA VIEWER / 動くREADME

複数のCSVをまとめ、
確認結果を共有する。

Reader Data Viewer は、複数のCSVから検索用データを作り、番号で該当レコードを表示し、人が確認した結果を共有Excelファイルへ反映する Windows アプリです。

01

OVERVIEW

何をするアプリか

端的に言えば、ばらばらのCSVを一つの検索対象にまとめ、確認した記録だけを複数人で共有するための道具です。

  1. データを準備する指定されたCSVを読み、設定ファイルに書かれた順番で結合・抽出・集計などを行います。
  2. レコードを探すこの画面へ番号を入力するか、別のアプリの入力欄から番号を読み取って検索します。
  3. 内容を確認する該当レコードを画面に表示します。複数見つかった場合は、利用者が候補から一つ選びます。
  4. 確認結果を記録するレコードの状態を「未処理」または「処理済」にします。変更は、まず利用者のPCに保存されます。
  5. 他の利用者と共有する「送信」を押した時だけ、手元に保存した変更を共有Excelファイルへ反映します。
共有Excelファイル
複数の利用者が同じ場所から参照する、一つのExcelファイルです。検索に使うデータと確認結果を保存します。
レコードの確認状態
表示中のレコードを確認したかどうかを示す値です。この仕様では「未処理」と「処理済」を使います。
実装上の補足技術担当向け

アプリ本体は C# / WinForms で動きます。CSVの読込、検索索引の作成、共有Excelの読書きは画面とは別の処理として実行し、操作中の画面を止めません。

共有ExcelはExcelアプリを起動せず、xlsxのZIP/XMLを直接読み書きします。

04

MULTI-USER SAFETY

複数人で使う仕組み

各PCが古い内容をそのまま書き戻すと、別の利用者の変更が消えます。このアプリは、共有ファイルを書き換える直前に最新内容を読み直します。

経路 A 台帳そのものを更新する

新しいCSVへ設定済みの処理を行い、その結果を共有Excelへマージ、置換または削除します。

経路 B レコードの確認状態を送信する

各PCに控えた「未処理／処理済」の変更だけを、共有Excelの該当レコードへ反映します。

書き換える内容は異なりますが、どちらも同じ安全な書き込み経路へ進みます。

確認状態を送信するときの流れ

  1. 1
    確認状態を手元へ保存

    「未処理」「処理済」の変更を、利用者のPCにある小さな未送信ファイルへ保存します。この時点では共有Excelファイルを変更しません。

  2. 2
    送信時に書き込み順を確保

    他のPCが書き込み中なら完了を待ちます。同時に二つのPCが共有ファイルを書き換えない状態にします。

  3. 3
    最新の共有Excelを読み直す

    アプリ起動時の内容ではなく、書き込みを始める直前のファイルを読みます。

  4. 4
    自分の未送信分だけを反映

    レコードを識別する列で照合し、手元に保存した現在の確認状態だけを更新します。照合できない変更は、捨てずに利用者へ知らせます。

  5. 5
    他のPCへ更新を知らせる

    更新を示す小さな情報ファイルを書き換えます。他のPCはその変化を検知した時だけ、共有Excelを読み直します。

  6. 6
    送信済みの手元データを削除

    共有Excelへの反映が完了した変更だけを、未送信ファイルから取り除きます。

実装上の補足二つの書き込み経路
経路 A台帳更新CSV処理の結果
経路 B確認状態の送信手元の未送信分
1同じ共有ロックを取得
2最新の共有Excelを読み直す
3自分の変更だけを反映
4一時ファイルから安全に置換
5新しい版を他のPCへ通知

両方とも同じ共有ロック取得処理を呼びます。片方が書き込み中なら、もう片方はロックが空くまで待つため、台帳更新と送信は互いに重なりません。レコード削除も同じ経路です。

ロックを取った後で最新のxlsxを読み直します。台帳更新はその最新版に対して処理結果を計算し直し、送信は識別できたレコードの確認状態だけを書き換えます。

書き込みは一時ファイルを完成させてから元のxlsxと置き換えます。実行中にHTTP通信やクラウドAPIは使いません。

状態は送信後も変更できます。処理済を未処理へ戻して再送信すれば、共有Excelにも現在の値が反映されます。

SCREEN & SCOPE

画面と機能の範囲

主画面は、検索、結果の確認、状態変更、送信、データ管理の順に並びます。承認済みの画面構成にない機能は追加しません。

アプリが行うこと

  • 設定されたCSVの読込と形式確認
  • 12種類のデータ処理の組み合わせ
  • 検索用データと共有Excelの作成・更新・削除・出力
  • 別のWindowsアプリの入力欄から値を読み取ること
  • 完全一致・部分一致・複数候補を含む検索
  • 確認状態の手元保存と明示的な送信
  • 複数PCからの共有ファイル利用
  • 設定や入力が不正な場合のエラー表示

アプリが行わないこと

  • バーコードリーダーなど実機の直接制御
  • 読み取り元の別アプリへの文字入力や操作
  • 特定業務だけに通用する判断
  • HTTP通信、クラウド保存、外部APIの利用
  • Excelアプリの起動や操作
  • 同じ現物を二人が同時処理する場合の調停
  • Excelの行上限に達した後の分割方法の自動決定

実装上の補足技術担当向け

主画面と各ダイアログは、Windows標準の WinForms コントロールを設定ファイルの画面定義に従って配置します。承認済みの画面構成にない部品は、実装側で補いません。

画面に出す値は定義された結び付けだけを使います。HTTP通信、クラウド保存、Excelアプリの自動操作は持ちません。

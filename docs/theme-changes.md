# 今回の変更範囲

この文書はタグ `v-multidesign-20260908` の6テーマ版の変更履歴です。現在の製品はWin98のみです。

基準：アップロードされた `ReaderDataViewer_fixed(1).zip`。Win98を既定とし、５種類のモダンデザインを追加しています。

## 更新した既存ファイル

| ファイル | 変更内容 |
|---|---|
| `build.bat` | 引数なしを複数選択TUIに変更。`compile` / `test`を維持し、PowerShellビルドコンソールへ転送 |
| `web/index.html` | テーマ属性と外観専用CSS／JSの読み込みを追加。既存業務JSと表示構造は維持 |
| `src/02_MainWindow.cs` | 背景・タイトルバー配色をテーマ化。副画面の測定完了後に外観専用通知を送信 |
| `README.md` | ビルド・配布・検証範囲を更新。旧READMEは `README.fixed-before-themes.md` として保存 |
| `tests/results/static-results.json` | 今回のソースに対して再実行した結果へ更新 |

## 追加した実装

`tools/Build.ps1` が６種類の選択、演出、サンプル有無、フォルダー／ZIP、通常時のC#検査、新規出力、マニフェストを担当します。`design/themes.json` が選択一覧です。

`web/themes.css` にモダン版の外観を隔離し、Win98に適用しない構造です。`web/theme-motion.js` は副画面が表示された直後の短いフェードだけを担当します。業務メッセージの送信・通信・タイマー・操作待機を追加していません。`web/theme.json` とHTML属性はビルド時に一組で生成し、`src/03_Theme.cs` がネイティブ配色だけを読みます。

開発用の検証・スクリーンショット・説明を追加しました。詳細は `theme-validation.md` と `design-build.md` を参照してください。

## 変更しなかった範囲

既存の業務処理・検索・IME処理・データ統合・状態遷移・監視・台帳競合・CSV/XLSX・共有・業務設定を担うソースは変更していません。`web/app.js`、`web/app.css`、`settings.json`、22個の既存C#（MainWindow以外）、ランチャー、DLL、元のデータ、元の試験の保全は `design/preserved-files.json` と `tests/test_theme_static.py` で確認できます。

各社の設計指針を参照した独自テーマであり、各社の公式ライブラリーやブランド資産を追加したものではありません。元のライセンスと第三者通知は保持しています。

## ビルドとアプリ機能の区別

新しい機能はビルド時の選択・配布です。アプリ内にテーマ選択画面を増やしておらず、生成された各アプリは固定テーマで起動します。元の起動時コンパイル方式のままで、単体EXE化・自動更新・データ移行機能は追加していません。

Windows実機検証は未実施です。ブラウザーや静的検査の合格と、ネイティブ動作の合格を混同しないでください。
